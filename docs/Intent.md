# Intent — 현재 작업

## 단계 1. 안정성·성능 (2026-11-13 시작)

1. **문제**: 복습 중 삭제된 문장을 평가하면 앱이 꺼질 수 있고, 미리 복습하면 간격이 부풀려지며, 첫 실행 때 키를 저장하면 탭이 튄다. 라이브러리·통계가 같은 전체 조회를 여러 번 메인 스레드에서 돌리고, AI 호출은 취소·재시도·오류 구분이 약하다. 출시용 빌드가 줄여지지 않는다.
2. **기대 결과**: 위 버그가 테스트로 재현된 뒤 고쳐지고, 화면은 그대로이면서 조회·계산이 줄고, AI 실패가 정확한 문구로 보이며, release 빌드가 R8로 줄어든다. 단위 테스트 407개 + 새 테스트 모두 통과.
3. **영향 범위**: `domain/Scheduler.kt`, `review/ReviewSession.kt`, `ui/review/ReviewViewModel.kt`, `MainActivity.kt`, `ui/library/*`, `data/EntryRepository.kt`, `stats/*`, `widget/*`, `reminder/*`, `ai/GeminiAiService.kt`, `AppContainer.kt`, `app/build.gradle.kts`.
4. **제약**: 화면 모양은 바꾸지 않는다(디자인은 단계 3). DB 스키마 변경은 단계 2에서 한 번에. 라이브러리 추가·버전 올리기는 승인 후.
5. **열린 질문**: 의존성 버전 올리기 승인 여부. 생각 예산·모델 고정(1-15)은 공식 모델 목록 확인 뒤 다시.

**상태(2026-11-13)**: 완료, 커밋함(f34a5c4~2826d01). 미리 복습은 "기한 전이면 지난 시간만 인정"으로 고쳤다(FSRS는 단계 2). 테스트 428개 통과, QA는 `docs/qa-guide.md`.

## 단계 2. DB v5 + FSRS (2026-11-13)

3. **영향 범위**: `data/*`(엔터티·마이그레이션·DAO·백업), `domain/Scheduler.kt`, `review/ReviewSession.kt`, 설정.
4. **제약**: 마이그레이션은 테스트 먼저, 데이터 삭제 금지. 스키마 변경은 이번 한 번.
5. **열린 질문**: 없음.

**상태**: 완료, 커밋함(bfe489a, e72579f). 테스트 432개 통과.

## 단계 13. 문장 끝 상태: 이미 알아요 · 통계에서 빼기 (2026-11-14)

   - 정답률을 흐리는 문장을 통계에서 뺄 방법이 없다(LingQ의 앎·무시처럼).
2. **기대 결과:**

     - 오늘 복습·위젯·7일/30일 예보·새 카드 수에서 빠진다.
     - 직접 골라 복습하면 나온다.

     - 라이브러리에서는 "도착 · 이미 알아요" 묶음과 "알아요" 칩으로 찾는다.
   - 통계에서 빼기: 정답률·익힌 정도·친구별·자주 틀리는 문장에서 빠진다. 복습은 그대로 하고, "통계 제외" 칩으로 찾는다.

   - DB: `entry.known`·`entry.excludeFromStats`(DB v6, 마이그레이션 5→6), 백업 v6.
   - `AppDao` 복습 차례 쿼리 4개.

   - `ui/library/*`.
   - `MainActivity`: 탭을 옮길 때 오늘 배지를 다시 읽는다.
4. **제약:**
   - 기존 문장은 모두 복습·통계에 남는다(기본값 0).
   - v5 이하 백업도 읽는다. 이 앱의 옛 버전은 v6 백업을 거부한다.
   - 문법 약점 기록은 통계 제외와 상관없이 그대로 센다.
5. **열린 질문:**

   - 실기기 마이그레이션은 아직 확인하지 못했다(에뮬레이터의 v5 DB는 데이터를 지킨 채 넘어갔다).

**상태:** 커밋함(8160369 + 리뷰 반영). 테스트 505개 통과. code-review 10개 중 9개를 반영했다. "알아요를 끄면 밀린 카드가 한꺼번에 돌아옴"은 하루 복습 한도가 막아 주어 그대로 둔다.
