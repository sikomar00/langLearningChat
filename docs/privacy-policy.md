# ChatLearn 개인정보처리방침 (초안)

> **초안입니다.** 운영자 정보와 연락처를 채우고, 배포 전에 현행 Google 약관과 대조해 검토해야 합니다.
> 대괄호 `[...]`는 비어 있는 항목입니다. 법률 검토를 거치지 않았습니다.

시행일: [YYYY-MM-DD]
운영자: [이름 또는 단체명]
문의: [이메일]

## 1. 요약
- ChatLearn은 서버를 운영하지 않습니다. 운영자는 사용자의 문장, 번역, 복습 기록, API 키를 **받지도 저장하지도 않습니다**.
- 저장한 문장과 복습 기록은 **사용자의 기기 안**에만 있습니다.
- 번역·첨삭·채점 같은 AI 기능을 쓰면, 그때 입력한 글이 **사용자가 직접 넣은 API 키로 Google Gemini API에 전송**됩니다.
- 광고, 분석 도구, 계정 가입이 없습니다.

## 2. 기기에 저장되는 정보
앱 전용 저장 공간(다른 앱이 읽을 수 없는 영역)에 다음이 저장됩니다.
- 사용자가 저장한 문장, 번역, 설명, 메모, 태그, 폴더
- 복습 일정과 복습 기록(내가 쓴 답, 판정, 해설, 응답 시간)
- 설정(모델 이름, 하루 목표, 알림 시각 등)
- Gemini API 키: 기기의 암호화 저장소(Android Keystore에 묶인 키)로 암호화해 저장합니다.

앱을 삭제하면 기기 안의 이 정보가 함께 삭제됩니다.

## 3. Google Gemini API로 전송되는 정보
다음 기능을 사용할 때만 해당 입력이 전송됩니다.
- 받은 말 번역: 붙여넣은 메시지
- 보낼 말 만들기: 한국어로 쓴 문장, (설정을 켠 경우) 내가 저장해 둔 표현 목록
- 첨삭: 내가 쓴 영어·스페인어 문장
- 복습 채점: 문제 문장, 정답, 내가 쓴 답
- 단어 뜻 보기: 누른 단어와 그 문장
- 저장 시 다른 언어 만들기, 핵심 표현 찾기: 저장한 문장

전송은 사용자가 설정에 넣은 **본인의 API 키**로 이루어지며, 운영자 서버를 거치지 않습니다.
전송된 내용의 처리는 Google의 약관과 개인정보 처리방침을 따릅니다. [배포 전 확인: 무료(결제 미연결) 이용 시
입력이 서비스 개선에 사용되고 사람이 검토할 수 있다는 현행 약관 문구와 그 시행일.]
- Google Gemini API 약관: https://ai.google.dev/gemini-api/terms

이름, 전화번호, 주소 같은 개인정보는 지우고 붙여넣기를 권합니다.

## 4. 음성 기능
- 듣기(발음): 기기에 설치된 음성 합성(TTS) 엔진을 사용합니다.
- 말로 답하기·따라 말하기: 기기의 음성 인식 서비스(예: Google 앱)를 호출합니다. 앱은 인식된 **글**만 받고
  음성 녹음은 받지 않습니다. 음성 인식 서비스의 처리는 해당 서비스 제공자의 정책을 따릅니다.

## 5. 백업
- 기기의 **자동 백업**(Android Auto Backup)이 켜져 있으면, 앱이 만든 스냅샷 파일(저장 문장, 번역, 복습 기록, 태그, 폴더)이
  사용자의 Google 계정 백업에 포함될 수 있습니다. API 키와 설정은 포함되지 않습니다.
  이 백업은 Google 계정 설정에서 사용자가 관리·삭제합니다.
- 사용자가 설정에서 **내보내기**를 하면 사용자가 고른 위치에 백업 파일이 만들어집니다. 그 파일의 보관은 사용자가 책임집니다.

## 6. 권한
| 권한 | 용도 |
|---|---|
| 인터넷 | Gemini API 호출, 키 발급·약관 페이지 열기 |
| 알림 | 복습 알림(기기 안에서만 예약, 서버로 보내지 않음) |
| 부팅 완료 수신 | 재부팅 뒤 복습 알림 다시 예약 |

## 7. 보관과 삭제
- 기기 안의 정보: 앱을 삭제하거나, 앱 안에서 문장을 삭제하면 지워집니다.
- Google 계정 백업: Google 계정에서 삭제합니다.
- Gemini API로 전송된 내용: 삭제는 Google의 정책을 따릅니다. 운영자는 이를 삭제할 수 없습니다(받은 적이 없습니다).
