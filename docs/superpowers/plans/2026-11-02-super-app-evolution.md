# ChatLearn 전면 점검·개선 계획 (2026-11-02)

사용자 요청: "UI·UX·사용성·유저 저니·기능 최적화, 앱 전체를 점검해 최고의 앱으로. 실기기 테스트만 빼고 모두 진행."
→ 승인 단계 없이 바로 진행한다(요청이 "모두 진행"). 검증은 단위 테스트 + 에뮬레이터(Pixel_3_API_29)만 쓴다. 연결된 폰은 건드리지 않는다.

## 1. 점검 결과 (현재 상태 기준)

### 이어받은 미완성 작업
- 다른 세션(ui-ux-theme-overhaul)이 남긴 커밋 안 된 작업: 폴더 정리(DB v4, 밀어서 폴더 이동·삭제, 선택 모드 폴더/삭제), 알게 된 날(상세에서 수정).
- 테스트 350개 통과. 다만 번역 화면에서 "알게 된 날"을 고르는 UI가 없다(ViewModel만 있음).

### 유저 저니별 문제
| 저니 | 지금 | 문제 |
|---|---|---|
| 받은 말 담기 | 채팅앱 복사 → 앱 열기 → "클립보드 내용으로 바꾸기" → "번역" → 저장 | 앱 안에서만 세 번 눌러야 한다. 큰 붙여넣기 버튼이 화면을 차지한다. |
| 보낼 말 | 한국어 입력 → 후보 → "복사하고 저장" | 저장 없이 복사만 할 수 없다. 결과 글자를 골라 복사할 수 없다. |
| 내가 쓴 문장 | 없음 | 직접 영어·스페인어로 써 보고 고쳐 받는 흐름(첨삭)이 없다. 언어 교환 앱에서 가장 많이 쓰는 기능. |
| 매일 복습 | 알림 → 앱(번역 탭으로 열림) → 복습 탭 → 시작 → 카드마다 입력칸 탭 → 입력 → 제출 → 스크롤 → 평가 | 알림이 복습 탭을 열지 않는다. 카드마다 입력칸을 눌러야 키보드가 뜬다. 평가 버튼이 화면 아래로 밀려 스크롤해야 한다. 철자 시험(빈칸·받아쓰기)에 키보드 자동 수정이 켜져 있다. 말하기 연습이 없다. |
| 다 끝낸 뒤 | "다시 확인"만 있음 | 오늘 새 카드 한도를 다 쓰면 더 배울 방법이 없다. |

| 설정 | 화면 탭은 시스템 색만 | 밝게/어둡게 고정, 발음(미국·영국, 스페인·중남미)·말 빠르기 선택이 없다. 마지막 백업이 언제인지 모른다. 키 발급 페이지로 가는 길이 없다. |
| 라이브러리 | 제스처 안내 문구가 늘 떠 있음 | 한 번 알면 필요 없는 문구가 목록 공간을 계속 차지한다. |
| 통계 | 최근 7일 막대 | 꾸준함을 보여 주는 장기 기록(달력형)이 없다. |

## 2. 개선 항목 (순서대로 진행)

### A. 이어받은 작업 마무리
- A1. 폴더·알게 된 날 작업을 그대로 커밋(작성자 세션 표시).
- A2. 번역 화면에 "알게 된 날" 칩 + 날짜 선택(과거만), 오늘로 되돌리기.

### B. 앱 안으로 들어오는 길
- B1. 인텐트 라우팅: 알림·바로가기·위젯이 보낸 "열 탭/동작"(`chatlearn.OPEN` 액션 값: review, paste, sent)을 해석하는 순수 함수 `launchRequestOf(intent)` + MainActivity 처리. 알림은 복습 탭을 연다.
- B2. 앱 바로가기(런처 아이콘 길게 누르기): 오늘 복습 / 붙여넣고 번역 / 보낼 말 쓰기.
- B3. 홈 화면 위젯(Glance): 오늘 복습 카드 수·목표·연속 일수, "복습"·"붙여넣기" 버튼. 저장·평가 뒤 갱신. 설정에 "홈 화면에 위젯 추가" 버튼(requestPinAppWidget).

### C. 번역 탭
- C1. 입력칸이 비었을 때 오른쪽 붙여넣기 아이콘 → 붙여넣고 바로 번역. 큰 버튼 제거. 바로가기·위젯의 "붙여넣기"는 창 포커스를 얻은 뒤 클립보드를 읽는다(Android 10 이상 제약).
- C2. 보낼 말 후보에 "복사만" 추가, 결과 문장은 길게 눌러 골라 복사할 수 있게(SelectionContainer).
- C3. 세 번째 모드 "첨삭": 내가 쓴 영어/스페인어 문장 → AI가 고친 문장, 바뀐 단어 강조(단어 단위 diff), 한국어 해설, 다른 표현, 자연스러우면 "그대로 보내도 돼요". 복사만 / 복사하고 저장(보낸 말로 저장, 핵심 표현·다른 언어 포함).

### D. 복습 탭
- D1. 아래 고정 행동 영역: 문제 화면은 특수문자·제출·정답 보기·나중에, 채점 화면은 평가 버튼이 항상 아래에 보인다(본문만 스크롤).
- D2. 새 카드가 나오면 입력칸에 자동 포커스. 키보드: 빈칸·받아쓰기는 자동 수정 끔, 정답 언어로 키보드 언어 힌트, 문장 입력은 첫 글자 대문자.
- D3. 말하기: 쓰기 번역에서 마이크로 답하기(음성 인식 → 입력칸), 채점 뒤 "따라 말하기"(정답 문장을 말하면 일치도 판정). 음성 인식 앱이 없으면 버튼을 숨긴다.
- D4. 다 끝냈을 때 남은 새 카드가 있으면 "새 카드 5장 더 배우기".

### E. 화면·설정·기타
- E1. 앱 아이콘(적응형 + 테마 아이콘용 단색), 창 배경 테마(낮/밤)로 시작 때 번쩍임 제거, 알림 아이콘.
- E2. 화면 모드: 시스템/밝게/어둡게.
- E3. 발음: 영어(미국/영국), 스페인어(스페인/중남미), 말 빠르기(느리게/보통/빠르게).
- E4. 백업: 마지막 내보내기 시각 표시, 오래됐으면 안내. AI 탭에 "키 발급 페이지 열기".
- E5. 라이브러리 제스처 안내는 "알겠어요"로 닫으면 다시 안 보인다.
- E6. 통계: 최근 12주 학습 달력(잔디).

### F. 검증
- F1. 에뮬레이터용 가짜 Gemini 서버(디버그 빌드에서만, 앱 전용 폴더의 `ai_base_url.txt`로 주소를 바꾼다. 평문 HTTP는 10.0.2.2만 허용)로 AI 흐름까지 화면 검증.
- F2. 배치마다 전체 단위 테스트 + 커밋. 마지막에 전체 시나리오 테스트와 자체 리뷰.

## 3. 원칙
- 로직은 테스트 먼저(RED 확인 → 구현 → GREEN). 화면은 에뮬레이터로 확인.
- DB 스키마는 v4 이후 바꾸지 않는다. 새 설정은 DataStore 키 추가로만.
- 실기기(연결된 폰)는 사용자가 요청할 때만 설치·조작한다(이번에는 마지막에 요청받아 확인함). API 키는 다루지 않는다.
