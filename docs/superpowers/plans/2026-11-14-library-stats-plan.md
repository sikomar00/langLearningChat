# 라이브러리·문장 상세·성장 개선 계획 (2026-11-14)

다른 외국어 학습 앱이 저장한 문장·단어 목록과 통계를 어떻게 보여 주는지 조사했다. 그 결과를 지금 ChatLearn(출국장 안내판 세계)과 견줘 고칠 곳을 정했다.
조사는 각 앱의 도움말·블로그·리뷰를 읽은 것이다(앱을 직접 열어 보지는 않았다). [U]는 공식 자료로 확인하지 못한 것이다.

## 1. 조사 요약

### 목록 한 줄(행)에 무엇을 보여 주나
| 앱 | 한 줄 내용 | 익힌 정도 표시 |
|---|---|---|
| Anki / AnkiDroid | 앞·뒷면, 기한, 간격, 덱. 모바일은 2열(둘째 열을 고를 수 있음) | 줄 색(정지·표시), 숫자 열(간격·ease·틀린 수) |
| LingQ | 단어·뜻, 어느 강의에서 왔는지 | 1 새로 봄 → 2 알아봄 → 3 익숙 → 4 익힘, ✓ 앎(복습 끝), 취소선 무시 |
| Busuu | 단어·뜻·예문·발음 [U] | 약함·보통·강함 막대. 이 셋이 곧 필터 버튼 |

| Migaku | 단어·문장·원문 소리·장면 | 모름 빨강 · 익히는 중 주황 · 앎 초록 · 무시 회색 |
| Language Reactor | 문장(자막 줄)·단어·맥락·영상 제목·날짜 | 불만: 문장 조각만 남고 앞뒤가 사라짐 |
| HelloTalk | 즐겨찾기한 메시지·교정 | 교정은 지운 말 빨강 취소선, 더한 말 초록 |

### 한 장 상세
- **Anki·RemNote:** 요약 칸 몇 개(다음·마지막 복습, 횟수, 걸린 시간)와 복습 기록 표(날짜·누른 평가·간격). FSRS면 망각 곡선도 그린다.
- **Mochi:** 기억함/잊음·날짜·간격·걸린 시간 기록.
- **Readlang:** 그 단어를 만난 문장을 모두 모아 두고 돌려 본다.

### 통계 화면
- **Anki:** 오늘 · 앞으로 기한 · 달력 · 성숙도별 카드 수 · 간격 · 시간대 · 버튼 비율 · 실제 기억률. 너무 빽빽해 전문가용이라는 평이 많다.
- **Mochi:** 반대로 "빈약하다"는 평.
- **RemNote:** 1년 달력 + 연속일, 주간 막대, 30일 예보(복습은 꽉 찬 막대, 새 카드는 테두리 막대), 숙달 단계 막대.
- **Duolingo:** 0~160 점수와 "할 수 있는 일" 문장(예: 익숙한 주제로 간단한 대화). 연속일·XP는 실력이 아니라 출석이라는 비판이 있고, 연속일 불안도 지적된다.
- **Memrise(2025):** 지난주·지난달의 나와 비교하는 화살표(늘면 초록, 줄면 빨강). "연속일보다 꾸준함"을 내세웠다.
- **Babbel:** 위에 목표·진도, 아래에 학습 통계, 연속일은 일부러 맨 아래에 둔다.

### 공통 원칙(여러 앱에서 되풀이)
1. 익힌 정도는 **이름 붙은 3~6단계**를 줄마다 작은 그림 하나로 보여 준다. 그 단계가 곧 필터 칩이다(Busuu, LingQ, Quizlet).
2. **어디서 왔는지**(강의·영상)를 필터와 묶음의 기준으로 쓴다(LingQ, Language Reactor). **맥락은 문장 통째로**, 앞뒤 줄과 함께 남긴다.
3. **끝 상태를 나눈다:** 앎(복습 그만) / 익힘(계속 복습) / 무시(통계에서 뺌). 사용자가 직접 올리고 내릴 수 있다(LingQ).
4. **자동 묶음:** 최근 틀림·가장 약함·별표. 손으로 목록을 만들게 하지 않는다(Babbel이 받는 불만).
5. 상세는 **요약 칸 몇 개 + 복습 기록**.
6. 통계는 **나와의 비교와 "할 수 있는 일"**이다. XP처럼 늘기만 하는 수, 리그, "연속일 깨지 마" 같은 손실 압박은 피한다.
7. **아무도 안 하는 것:** 저장한 말을 **친구(대화 상대)별로 묶기**, **고친 말 전후 보기**(HelloTalk만 채팅 안에서). ChatLearn만 할 수 있는 자리다.

출처는 문서 끝에 있다.

## 2. 지금 ChatLearn과 비교
| 항목 | 지금 | 빈 곳 |
|---|---|---|
| 줄의 익힌 정도 | 5칸 불빛(이름 없음), 상태 알약(복습할 차례/n일 후/새 문장) | 단계에 **이름**이 없고 **필터로 못 씀** |
| 출처(친구·나라) | 목적지 칸에 글자로 | **친구별 묶기·필터 없음**(태그 묶기에 섞여 있음), 대화로 돌아가는 길이 약함 |

| 상세 | 문장 탑승권(횟수·마지막·다음 복습) | **복습 기록(날짜·방식·내 답·평가)** 없음. 앞뒤 대화가 아래쪽 접힌 칸에 있음 |

## 3. 개선 계획 (안내판 세계 안에서, 화면 구조는 유지)

### A. 라이브러리 (먼저)
- **A1. 익힌 단계에 이름 붙이기:** 0 새 문장 · 1~2 익히는 중 · 3~4 거의 · 5 익힘. 줄의 불빛 옆에 이름은 넣지 않고, 필터 칩에 `익히는 중 12` 처럼 안내판 숫자로 센다.
  - 같은 이름을 상세와 성장에서도 쓴다. 숫자 계산은 그대로 둔다.
- **A2. 친구별 묶기와 필터:** "묶기"에 **친구별**을 더해 사람 태그로 묶는다(친구 없음은 맨 끝). 머리 줄은 `Lucia · 스페인 12`.
  - 필터에 친구 칩 줄을 둔다.
- **A3. 자동 묶음 칩:** `최근 틀림`(지난 7일에 "다시"를 누른 문장)과 `곧 복습`(3일 안).
- **A4. 끝 상태(결정 필요):**
  - **이미 알아요:** 복습에서 빼고 단계 표시는 ✓.
  - **통계에서 빼기:** 정답률·익힌 정도에서 제외.
  - DB에 값 하나가 필요하다(v6 마이그레이션, 백업 형식 포함).

### B. 문장 상세
- **B1. 복습 기록:** 탑승권 아래 "탑승 기록" 표. 한 줄에 날짜(안내판 숫자) · 방식(빈칸·번역·받아쓰기) · 내 답 · 평가(색 점 + 글자)를 두고, 최근 10개만 보이고 더 보기로 펼친다. 데이터는 이미 있다(review_log).
- **B2. 대화를 위로:** 앞뒤 대화가 있으면 탑승권 바로 아래에 말풍선으로 보여 준다. 저장한 줄만 굵게 하고 나머지는 흐리게 한다.
- **B3. 단계 변화 그림:** 복습할 때마다 단계가 어떻게 올라갔는지 5칸 불빛을 작은 계단처럼 시간순으로 그린다(Anki 망각 곡선의 쉬운 판). 데이터가 있을 때만.

### C. 성장
- **C1. 맨 위를 "나와의 비교"로:** 띠 세 칸을 `익힌 문장 n (이번 주 +k)` · `이번 주 복습 n (지난주 대비 ▲/▼)` · `정답률`로 바꾼다. 늘면 초록, 줄면 회색으로 하고, 빨간 손실 표시는 쓰지 않는다.
- **C2. 담담한 사실 한 줄:** 기록에서 나오는 사실만 쓴다. 예: "스페인어 문장 23개를 익혔어요. 그중 15개가 Lucia와의 대화에서 왔어요." 기록으로 뒷받침되지 않는 "~를 할 수 있어요" 같은 실력 주장은 하지 않는다.
- **C3. 친구별 성장:** 친구마다 문장 수와 익힌 비율을 막대로 보여 준다(어느 앱도 안 하는 것).
- **C4. 연속일은 아래로, 부드럽게:** 맨 위에서 내려 달력 옆에 "이번 달 n일 복습"으로 둔다.
- **C5. 정답률 표 4개를 하나로:** 정답률 칸 하나에 `언어 · 방식 · 태그` 전환 칩을 둔다.
- **C6. 자주 틀리는 문장:** 누르면 문장 상세가 열리고, "이 문장만 복습"을 할 수 있다.
- **C7. 예보:** 오늘 화면의 7일 예보는 그대로 두고, 성장에는 30일 예보를 RemNote처럼 넣는다(복습은 꽉 찬 막대, 새 카드는 테두리 막대).

**계획과 달라진 점:**
- C1 "익힌 문장 n (이번 주 +k)"에서 +k는 뺐다.
  - review_log에 복습 뒤 간격이 없어 정확히 셀 수 없다.
  - 어림값이 이른 복습 때마다 +1로 잘못 세었다.
  - 대신 "전체 n문장 중"을 쓴다.
- C1 비교 표시는 초록·▲ 대신 밝기와 "+N" 꼴로 했다. 검은 판 위 초록 작은 글씨는 대비가 모자라고, 호박은 "지금·선택" 전용이다.
- B3 단계 계단은 어림값이다. 첫 복습은 1, 이후는 앞 복습부터 기억한 기간으로 매긴다. 기록이 4개 이상일 때만 보인다.
- "이 문장 복습" 버튼을 상세에 더했다(C6의 "이 문장만 복습").
