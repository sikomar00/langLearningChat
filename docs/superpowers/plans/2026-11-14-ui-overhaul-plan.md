## 1. 한눈에 요약
**지킬 것:**
- 라이브러리 출발 안내판 줄(시간·편·상태·모양으로 구분한 거리 막대).
- 번역·복습·상세가 같은 탑승권을 쓰는 것.
- 복습 평가 4개 + 다음 간격.
- 글자 대비는 모두 4.5:1 이상이다.
- 화면 코드에 hex를 직접 쓴 곳이 없다.

**고칠 것은 여섯 갈래다:**
1. **색 규칙이 깨진 곳.**
   - 호박이 "지금·선택" 밖에서 쓰인다: 듣기 버튼, 상세 저장, 다크 tertiary.
   - 보조 버튼 글자가 회색이라 꺼진 버튼처럼 보인다.
   - 정보를 담은 그래픽의 대비가 바탕과 3:1이 안 된다(히트맵, 꺼진 칸, 익힌 정도).
2. **구역·간격·제목이 화면마다 다르다.** 오늘 화면만 판이 없고, 간격이 12/16/20/24로 섞여 있다.
3. **핵심 흐름이 길다.**
   - 번역 결과의 "저장"이 화면 밖에 있다.
   - 문장 상세는 편집칸이 늘 펼쳐진 긴 스크롤이다.
   - 오늘 화면과 라이브러리에서 "지금 탑승"의 뜻이 다르다.
4. **라이브러리 구조.**
   - 서랍이 화면 가운데에 끼여 있다.
   - 선택 모드의 버튼이 2줄로 넘친다.
   - 필터 줄 이름표와 언어/나라 칩이 헷갈린다.
5. **말과 단위가 섞여 있다.** 장/개/회, 자주 틀린 것/문장, 노션/노션에 보내기.
6. **접근성·적응.**
   - 설정 화면이 키보드에 가려진다.
   - 채점 공개·숫자 설정 값을 알리지 않는다.
   - 글자 1.3배에서 겹친다.
   - 큰 목록이 매번 다시 그려진다.

- 펼침 버튼(필터·대화 보기): "펼쳐짐/접힘" 상태를 알린다.
- 설정 백업 탭의 배지: "백업 필요"로 읽힌다.
- 저장한 말풍선: "저장한 문장"으로 읽힌다.

**UI-6-3 바꿀 곳:**
- "✓ 휴대폰 설정"이 경계에 닿는다. 글자를 "기기 설정"으로 줄이고 두 줄까지 허용한다.

**UI-6-4 바꿀 곳:**
- predictive back을 켠다(`enableOnBackInvokedCallback`).
- TabRow → PrimaryTabRow.
- 태그 칩은 칩 전체가 아니라 ✕ 아이콘을 눌렀을 때만 지운다.

**UI-6-5 바꿀 곳:**
- 줄마다 넘기던 `now`를 1분 단위로 바뀌는 값으로 바꾼다.
- 검색·필터·정렬 combine에 `flowOn(Default)`를 붙인다.
- `visibleIds`를 `remember`로 감싼다.
